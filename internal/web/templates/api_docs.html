Create and update links
mutation {
  createShortURL(input: {longUrl: "https://example.com/article", customSlug: "article"}) {
    shortCode
    shortUrl
  }
}

Use updateShortURL to change a link. Omitted fields stay unchanged; explicit null clears optional fields. Select visits or redirectRules on a short URL to fetch them in the same query.

Authentication, limits and errors

Send X-Api-Key: <key> or Authorization: Bearer <key>. Admin keys have full access. Author keys manage their own links. Domain keys manage links on their assigned domain. Only admin keys can change shared tags or view global statistics.

Queries support GET and POST. Mutations require POST. Requests are limited to 1 MiB, 10,000 parser tokens and 10,000 complexity points; requested page sizes increase query cost. POST requests use the configured API rate limit. Introspection requires authentication. Subscriptions are not supported.

Authentication failures use HTTP 401. Resolver failures appear in errors, with extensions.code and extensions.status. Always check errors even when HTTP status is 200. Webhook operations require webhooks to be enabled. Newly created keys and webhook secrets are returned once; list queries return an empty string in those fields.
