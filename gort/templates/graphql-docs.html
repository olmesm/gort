Create and update short URLs
mutation {
  createShortURL(input: {longUrl: "https://example.com/article", customSlug: "article"}) {
    shortCode
    shortUrl
  }
}

Use updateShortURL to change a short URL. Omitted fields stay unchanged. Set title, group, validSince, validUntil or maxVisits to null to clear them. Set tags to [] to remove all tags. Select visits or redirectRules on a short URL to fetch them in the same query.

Authentication, limits and errors

Send X-Api-Key: <key> or Authorization: Bearer <key>. Admin keys have full access. Author keys manage short URLs created with that key. Domain keys manage short URLs on their assigned domain. Only admin keys can change shared tags or view global statistics.

Queries support GET and POST. Mutations require POST. Requests are limited to 1 MiB, 10,000 parser tokens and 10,000 complexity points; requested page sizes increase query cost. POST requests use the configured API rate limit. Introspection requires authentication. Subscriptions are not supported.

Authentication failures use HTTP 401. Resolver failures appear in errors, with extensions.code and extensions.status. Check the errors field even when the HTTP status is 200. Webhook operations require webhooks to be enabled. Newly created keys and webhook secrets are returned once; list queries return an empty string in those fields.
